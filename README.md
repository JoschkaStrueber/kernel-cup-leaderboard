# Christmas Kernel Cup leaderboard

This repository builds the leaderboard page of the Christmas Kernel Cup, the optional GPU kernel competition of the LLM Engineering course. Every 30 minutes a workflow reads each pair's newest results from the `kcup` branch of its repository and publishes one static page with two division tables, a heatmap and score history per team, and a chart of the leading scores. The scores are measured by the pairs themselves on UC3. They stay provisional until the staff re-run after the freeze, which sets the final ranking. The page shows nicknames only, never names, repository names or code. Each table also shows two reference rows, placed among the ranked teams by score: the unchanged starter and PyTorch's bf16 `F.cross_entropy`, both timed by the staff in one job (`baselines/starter.json`). They are never ranked. `leaderboard.json` next to the page holds the same data.

The kit lives in [`LLM-Engineering-26-27/kernel-cup`](https://github.com/LLM-Engineering-26-27/kernel-cup). Its README explains the task, the rules, how to measure on UC3 and how to submit. This repository is maintained by the course staff and changes only through the course's publish script.
